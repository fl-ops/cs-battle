Полноценный клиентский веб-симулятор открытия кейсов, апгрейдов и кейс-батлов в стилистике **CS Battle** и **Counter-Strike 2**. 

Работает на 100% в браузере, не требует бэкенда, базы данных или сторонних npm-библиотек. Поддерживает запуск локально, деплой на **GitHub Pages**, Vercel, Telegram Mini Apps, VK Play и Яндекс Игры.

---

## 🎮 Ключевые возможности

### 1. 📦 Кейсы и рулетка (CS Battle Style)
- **15 тематических кейсов:** от бесплатного ежедневного и бюджетной *Фармилки* до *Ножевого Батла*, *Перчаточного Рая* и *Драконьего Логова* (AWP Dragon Lore, Howl, Gungnir).
- **Мульти-открытие:** режимы **1X, 2X, 3X, 4X, 5X** одновременно.
- **Плавная рулетка:** физическая кривая замедления `cubic-bezier`, процедурный тикающий звук каждого пролетающего скина и подсветка выигрышной карточки.
- **Режим Fast Open:** мгновенное открытие для быстрой игры.

### 2. ⚔️ Режим Кейс Батлов (Case Battles)
- **Форматы:** 1 на 1 и 1 на 1 на 1 против умных ботов.
- **2 режима игры:**
  - **Классический (Classic):** побеждает игрок с наибольшей суммарной стоимостью дропа.
  - **Сумасшедший (Crazy Mode):** побеждает игрок с **наименьшей** суммарной стоимостью дропа!
- Пошаговое синхронное вскрытие кейсов с живым табло очков. Победитель забирает дроп всех участников.

### 3. ⚡ Круговой Апгрейдер (Canvas 360° Upgrader)
- Высокопроизводительный рендеринг на **HTML5 Canvas 2D (60 FPS)** с кэшированием статического безеля в Offscreen Canvas (без лагов при любых шансах).
- **Симметричная зона выигрыша:** неоновая полоса шанса равномерно раскрывается в обе стороны от нулевой точки.
- **Быстрые пресеты шанса:** `5%`, `10%`, `25%`, `50%`, `75%` с автоподбором скина под выбранную вероятность.
- **Множители цены:** `x1.5`, `x2`, `x3`, `x5`, `x10`, `x20`, `x50`.
- **Буст монетами:** возможность доплатить балансом до +25% от стоимости скина для пропорционального увеличения шанса.
- В центре рулетки — золотой рельефный керамбит и высокоточная неоновая стрелка.

### 4. 🔫 База из 212 скинов CS2
- **Ножи и перчатки:** Керамбиты, Ножи-бабочки, M9 Байонет, Скелетные ножи, Спортивные перчатки, Перчатки спецназа.
- **Культовое оружие:** AWP Dragon Lore, Gungnir, Asiimov; AK-47 Wild Lotus, Fire Serpent, Vulcan, Bloodsport; M4A4 Howl, Poseidon; M4A1-S Printstream; Desert Eagle Blaze и др.
- Честные коэффициенты цен, сбалансированные под реальную экономику CS.

### 5. 📜 Контракты обмена (Trade-Up Contracts)
- Крафт от 3 до 10 скинов одной редкости для получения предмета более высокого класса.

### 6. 🎒 Инвентарь и экономика
- Игровая валюта: **🪙 Дропы** (безопасные виртуальные монеты).
- Мгновенная продажа отдельных предметов, кнопки **«Продать всё»** и **«Продать дубликаты»**.
- Фильтры по типу оружия, редкости и стоимости.
- Автоматическое сохранение прогресса в `localStorage` (с поддержкой облачных сохранений при интеграции с игровыми порталами).

### 7. 🔊 Процедурный Web Audio синтезатор
- Все звуки (клики, тики рулетки, звон монет, фанфары победы) генерируются на лету через **Web Audio API** без внешних тяжелых mp3/wav файлов.

## 🚀 Быстрый запуск

### Вариант 1. Запуск в один клик через GitHub Pages
1. Перейдите в ваш репозиторий на GitHub.
2. Откройте **Settings** → **Pages** (в левой колонке).
3. В блоке **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (или `master`) / папка `/ (root)`.
4. Нажмите **Save**. Спустя 1-2 минуты ваша игра станет доступна по ссылке:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Вариант 2. Локальный запуск
Так как проект написан на чистом ванильном стеке (HTML/CSS/JS), для запуска не требуется сборка `npm run build`:

```bash
# Клонируйте репозиторий
git clone https://github.com/<ваш-логин>/<имя-репозитория>.git
cd <имя-репозитория>

# Откройте index.html в любом браузере
# Либо запустите локальный веб-сервер:
python3 -m http.server 8000
# Игра будет доступна по адресу http://localhost:8000
```

## 🛠️ Архитектурные особенности

- **Zero-Dependency:** 0 внешних библиотек или npm-пакетов. Мгновенная загрузка страницы (< 1.5 сек).
- **Offscreen Canvas:** Фоновый слой шкалы рулетки апгрейдера генерируется один раз в буфере памяти, гарантируя стабильные 60 FPS на экранах высокой четкости (Retina / 4K).
- **Graceful Degradation SDK:** Если платформенный SDK (Яндекс, VK или др.) отсутствует или заблокирован адблоком, игра автоматически переключается в локальный оффлайн-режим с сохранением всего прогресса в `localStorage`.
- **Mobile First / Touch Friendly:** Полная поддержка сенсорного ввода и адаптация под мобильные экраны.
